# python_code

Python practice code from the *Python for Everybody* specialization (University of Michigan, Coursera): core Python, data structures, web data and databases.

## Contents
| Folder | Topics |
|---|---|
| [01-Python_for_Everybody_Specialization](./01-Python_for_Everybody_Specialization) | Input/output, operators, conditionals, try/except, functions, loops |
| [02-Python_Data_Structures](./02-Python_Data_Structures) | String, file, list, dictionary and tuple methods, regular expressions |
| [03-Using_Python_to_Access_Web_Data](./03-Using_Python_to_Access_Web_Data) | HTTP requests, parsing HTML, XML and JSON, calling APIs |
| [04-Using_Databases_with_Python](./04-Using_Databases_with_Python) | SQLite and SQL, one-to-many and many-to-many tables, loading JSON and XML into a database, object-oriented Python |

## Notes
- Course exercises, kept as a record of practice. Sample data files (`mbox.txt`, `romeo.txt`, `roster_data.json`) come from the course.
- API keys and tokens are not included. The `hidden.py` files contain placeholders only.
- The `Old_twitterAPI_Example` and `OldTwitterCode` folders use the retired Twitter v1 API, so they are kept for reference only.
